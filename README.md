# おすそわけ収穫 愛媛版デモ

収穫期の人手が足りない農家さんと、野菜を必要とする人を「収穫のお手伝い」でつなぐマッチングアプリのデモです。お礼は現金ではなく、規格外野菜のおすそわけです。

- 対象地域：愛媛県（松山市周辺）
- 農家・参加者・数値はすべて架空のものです。
- サーバーは不要です。HTML ファイルをブラウザで開くだけで動きます（地図・天気の表示にはインターネット接続が必要です）。

## フォルダの中身

| ファイル | 内容 |
|---|---|
| `osusowake-ehime-smartphone.html` | **スマホ版デモ**（参加者・農家アプリ）。スマホでは全画面で表示されます。画面右端の縦長のタブ「デモ案内」から、画面の一覧を開けます |
| `osusowake-demo-ehime.html` | **PC 版デモ**（同じアプリ）。スマホの枠の横に、画面の一覧と対応する要件が並びます |
| `osusowake-admin-ehime.html` | **運営管理画面**のデモ（PC 向け） |
| `docs/backend-requirements-amplify.md` | **バックエンド要件定義書**（Amplify Hosting 版）。API、DynamoDB、外部 API、AWS 構成、3 人での 1 日の進め方 |
| `docs/demo-amplify-architecture.png` / `.svg` | AWS 構成図（Amplify Hosting・DynamoDB・外部 API） |
| `tools/update_prices.py` | 野菜価格（e-Stat）を最新にするスクリプト |
| `tools/make_mobile.py` | PC 版からスマホ版を作り直すスクリプト |

## 開き方

1. パソコン：`osusowake-demo-ehime.html`（PC 版）または `osusowake-ehime-smartphone.html`（スマホ版）をダブルクリックして、Chrome・Edge・Safari などで開きます。
2. スマホ：`osusowake-ehime-smartphone.html` をスマホに送って、ブラウザで開きます。
   - 送ったアプリの中のプレビューでは動かないことがあります。その場合は「ブラウザで開く」を選んでください。
3. Web で公開する場合は、このフォルダをそのまま静的サイトとして置けます（Amplify Hosting、S3 など）。

## デモの見どころ

| 画面 | 操作 |
|---|---|
| さがす | 日付は開いた日に合わせて自動で更新され、募集の少ない日は募集が自動でつくられます。上に天気（気象庁）が出ます |
| 地図 | 「地図」を押すと、国土地理院の地図に募集のピンが出ます。ピンを押すと詳細が開きます |
| 募集の詳細 | お礼の野菜を市場価格に換算した金額（e-Stat、松山市）と、当日の天気が出ます |
| 応募締切 | 締切を過ぎた募集・「受付終了」の募集はグレーになり、応募ボタンが押せません（今の時刻で判定） |
| 同じ日の応募 | 参加予定のある日（デモでは「みかんの収穫と選果」の日）に別の募集へ応募すると、「応募できません」画面が出ます |
| 参加のリクエスト | さがす画面の上の「あおいさんから参加のリクエスト」から、同意して「参加する」と回答できます |
| メンバー連携（送る） | マイページ → 参加メンバー → 新しくメンバーを連携する → ID `kenta_iyo` で検索 → リクエスト → 相手の画面（デモ）で承認 → 確認コード `4821` を入力 |
| メンバー連携（受け取る） | お知らせ、または マイページ → 参加メンバー の「届いている連携リクエスト」から、なつさんのリクエストを承認 → 確認コード `3907` が出る → 「なつさんがコードを入力した（デモ）」 |
| メッセージ | 農家さん・参加者のグループ・運営の 3 つの会話を開けます。運営に送ると自動返信が届きます |
| 農家モード | マイページの「農家モードに切り替える」、またはデモ案内の「農家」から。募集づくり・応募者の承認・当日の受け入れ（QR）など |

デモの状態はページを読み込み直すと最初に戻ります。

## 使っている外部データ（すべて無料・API キー不要）

| データ | 提供元 | 取得のしかた | 出典表示 |
|---|---|---|---|
| 地図 | 国土地理院「地理院タイル」 | 表示のたびにブラウザから読み込み（常に最新） | 地図の右下に「地理院タイル」 |
| 天気 | 気象庁の天気予報（愛媛県・中予・松山） | 開いたときにブラウザから取得し、30 分保存 | 天気の欄に「気象庁」 |
| 野菜価格 | 政府統計の総合窓口（e-Stat）小売物価統計調査「主要品目の都市別小売価格」（松山市） | `tools/update_prices.py` で取り込み、HTML に保存（現在は 2026 年 9 月分、柿は 2025 年 12 月分） | 換算金額の下に出典 |

- 地図のライブラリ（Leaflet）と文字（Google Fonts）はインターネットから読み込みます。オフラインでは地図・天気が表示されず、文字は端末の標準フォントになります。
- 野菜価格は小売価格をもとにした目安で、実際の価値とは異なります。
- 地図のピンは農園のある地区のおおよその位置です。

## 野菜価格を最新にする（月に 1 回）

e-Stat は毎月下旬に前月分を公開します。Python 3 と openpyxl があるパソコンで、このフォルダで次を実行します。

```bash
pip install openpyxl
python tools/update_prices.py
```

最新月のファイルを自動で探して PC 版の HTML に値を書き込み、スマホ版も作り直します。

## 画面を直すとき

PC 版の `osusowake-demo-ehime.html` を編集し、次でスマホ版を作り直します（スマホ版は直接編集しないでください）。

```bash
python tools/make_mobile.py osusowake-demo-ehime.html osusowake-ehime-smartphone.html
```

## 注意

- 運営管理画面（`osusowake-admin-ehime.html`）の日付は自動で更新されません（2026 年 10 月末を想定した固定の画面です）。
- バックエンド（API・DB）は未構築です。構築するときは `docs/backend-requirements-amplify.md` に従ってください。提供 AWS 環境の制約（名前の先頭に `EhimeAI2026-`、`Project` タグ必須、東京リージョン など）に合わせてあります。
